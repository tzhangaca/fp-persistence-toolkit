# Release status

Version `0.2.0` follows the tested `0.2.0rc3` candidate. The comparison methods are unchanged; this version adds citation metadata and aligns the source, documentation and tests with the release version. GitHub Actions checks the package and the published `fp-persistence-audit==0.1.2` engine on Python 3.10–3.13. See the latest Actions run for test results.

The example uses artificial transactions. The toolkit reports descriptive model-instance comparisons, not a statistical test of superiority, real-world payment declines, or consumer harm. It does not reproduce the paper's complete FDH training, context-building or RQ2 inference pipeline.

GitHub Releases contains the tagged source archives. The package is not distributed through PyPI. A Zenodo DOI should only be cited after the repository's release has been archived successfully.
