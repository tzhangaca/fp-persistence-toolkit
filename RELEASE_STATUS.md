# Release status

Version `0.2.0rc3` has passed all 38 automated tests on Python 3.10–3.13 through GitHub Actions, including integration with the published `fp-persistence-audit==0.1.2` engine and the end-to-end example.

The toolkit is available as public source code. A tagged GitHub pre-release is being prepared; the package has not been published to PyPI.

The included example uses synthetic transactions. The toolkit provides descriptive comparisons of repeated false-positive concentration and does not establish real-world payment declines, consumer harm, or model superiority. It is not a complete reproduction of the paper's FDH experiments or RQ2 inference.
